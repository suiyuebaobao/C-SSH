# C-SSH 0.9.9

[简体中文](README.md) · [Website](https://c-ssh.com/en) · [Install](INSTALL_EN.md) · [Features](FEATURES_EN.md) · [Self-hosting](SELF_HOSTING_EN.md) · [Changelog](CHANGELOG_EN.md)

C-SSH brings host management, terminals, files, monitoring, and an AI assistant into one client. This release adds the Linux x86_64 AppImage, aligned with the Mac 0.9.9 interface and workflows.

## What's changed

- Improves switching, progress display, and task controls when multiple AI conversations are running.
- Improves cloud sign-in, page loading, and startup.
- Fixes display issues in some tool and search results.

The Windows, Mac, and Android 0.9.9 files are unchanged. Existing users of those builds do not need another download. Download and installation remain manual, with no automatic or forced upgrade.

## Main features

- Manage hosts, terminals, files, and monitoring through Agent or plain SSH connections.
- Use AI across all hosts, a project, or one host, with visible progress and results.
- Manage and sync cloud configuration manually, or use local features without signing in.
- The desktop server browser uses Google Chrome. This feature is not currently available on mobile.

See [Features](FEATURES_EN.md) for platform differences. The relevant Linux interface, AI conversation flows, and data retention after upgrading were tested; this does not cover every distribution or network environment.
